# 🎮 Игровой портал

Учебный проект — мини-игровой портал в тёмной теме с каталогом, поиском и фильтром по категориям. Внутри 8 играбельных мини-игр на чистом HTML, CSS и JavaScript. Без фреймворков, без сборки, без внешних зависимостей.

## ✨ Возможности

- 🕹 **8 мини-игр** разных жанров — аркады, головоломки, логика, слова
- 🔍 **Поиск** по названию и категории
- 🏷 **Фильтр по категориям**
- 🌙 **Тёмная тема** в стиле современных игровых порталов
- 🪟 **Модальное окно** для запуска игры прямо на странице
- 📱 **Адаптивная вёрстка**
- ⚡ **Один файл** — весь проект в `index.html`

---

## 🎯 Игры

| # | Игра | Жанр | Описание |
|---|------|------|----------|
| ⚡ | Реакция | Аркады | Успей нажать при смене цвета. Ведётся рекорд. |
| 👆 | Кликер | Аркады | Максимум кликов за 10 секунд. |
| 🧩 | Память | Головоломки | Найди все пары эмодзи за минимум ходов. |
| 🔢 | Угадай число | Головоломки | Компьютер загадал 1–100, подсказывает «больше/меньше». |
| 🎨 | Саймон | Логика | Повтори растущую последовательность. 8 уровней. |
| ❌ | Крестики-нолики | Логика | Против ИИ с блокировкой и выигрышем. |
| ✊ | КНБ | Логика | Камень-ножницы-бумага со счётом. |
| 📖 | Виселица | Слова | Угадай слово по буквам, 6 ошибок — проигрыш. |
